A command is three words, then extra arguments: menu, action, and id. The function name is `idm_<menu>__<action>`.

Core actions live under the menu `core` in the source. The help text, the bashrc snippet, and `i` use the short words `enable`, `activate`, and `install`. Where the live parser does not select the function, the [limits]({{< relref "/concepts/limits" >}}) page is the authority.

The other pages in this section list the words, the variables, and the directories.
