idmgr is a sourced shell tool. The checkout is the program, and the test image is a throwaway container with the tree mounted read-only.

The toolkit is mise. `mise.toml` pins bats, hugo, and task. Versions stay there. Task commands do not pin them again.

The license string in `bin/idmgr` is `IDM_LICENSE='MIT'`. The version string next to it is `0.1 (beta)`.

Development commands, the test task, and how to serve this site are on the development page.
